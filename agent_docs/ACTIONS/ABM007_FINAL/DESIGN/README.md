## How to open

Open any HTML file in a browser from this folder structure. Nothing is fetched from the network. To change the look, change the hex values in `gen_tokens.py` and regenerate; do not edit colors in the pages and do not hand-edit the precise triplets.

## How to rebuild

From `source/`: `python3 gen_tokens.py ..`, then `python3 build_refs.py ..`, then `node render_refs.mjs ..`, then `node verify_colors.mjs ..`. Playwright with Chromium is expected on the machine; the two `.mjs` scripts name the Playwright path used in the authoring workspace and may need that one line changed.

## Limits

- **Fictional, approximate content.** The samples show the look. They are not a specification of today's fields, wording or flows; `CONTRACTS/UI_SPEC.md` and the real components are. A missing or reordered item on a sample approves nothing.
- **The menu is a picture.** The menu button does nothing on these static pages. `04b` draws the open state. On the mobile samples the name and role label sit inside that menu; the real apps keep whatever they do today.
- **Static states.** Hover, focus, disabled and busy are drawn as fixed examples on the style tile, not as live interactions.
- **Token evidence, not app evidence.** The color verification proves the token file and the reference stylesheet. Measuring the two built apps is independent QA's job (AC-B01, AC-B08).
- **Not built with the apps' Tailwind setup.** The pages use plain CSS over the same tokens. They are a visual target, not code to paste.
- **No final icon files.** The app icon, touch icon, favicon, email and Stripe files are engineering deliverables under `CONTRACTS/LOGO_ASSET_SPEC.md`.
- **The October Portal design package** was used as a reference for states and for the idea of a token-driven tile. Its screens, Saira, coral theme, dark mode, demo notices and placeholders are not carried over.
