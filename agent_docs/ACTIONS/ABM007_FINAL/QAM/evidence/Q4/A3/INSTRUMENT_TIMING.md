Firefox's initial broad matrix uses confirm-dispatch-clock.mjs and samples from inside the native click dispatch. Its zero-time task can observe the old page position and old focus before native anchor activation completes. The first results remain in firefox-results.json. The unchanged A2 Firefox procedure measures after Playwright returns, and all four original positions reached and stayed at zero. Chrome and WebKit use confirm.mjs, which makes the first measurement immediately after the browser input command completes and measures the other four against that timestamp. The Firefox post-input comparison uses the same method in a separate file. No scroll, focus, animation-frame or target wait intervenes after input. Only the anchor activations and sequential-Tab check need that comparison. Each context is closed before the next one opens.
